## Architecture

**Next.js 16 App Router** static portfolio site. All pages are statically generated at build time (no server-side runtime).

### Routing

- `src/app/page.tsx` — Single-page home assembling section components: Navbar → Hero → Projects → Experience → About → Footer
- `src/app/projects/[slug]/page.tsx` — Dynamic detail pages for each project, generated via `generateStaticParams()` from the projects data array
- Next.js 16 uses **async params**: `params: Promise<{ slug: string }>` (must `await params`)

### Data Layer (`src/data/`)

All content lives in typed TypeScript arrays — no CMS or API calls:

- `projects.ts` — `Project[]` with slug, title, description, techStack, liveUrl, asset paths
- `experience.ts` — `ExperienceEntry[]` for timeline section
- `techStack.ts` — `TechItem[]` with `brandColor` hex for the hero marquee icons
- `techBrandColors.ts` — `Record<string, {border, text, bg}>` mapping tech names to brand colors, used by ProjectCard badges. Has a `defaultBadgeColors` fallback for unmapped names
- `socials.ts` — Contact info (email, phone, LinkedIn, GitHub URLs)

### Styling

- **Tailwind CSS v4** via `@tailwindcss/postcss` plugin — no `tailwind.config.ts`
- All custom design tokens are defined in `src/app/globals.css` using `@theme inline { ... }` syntax
- Key color tokens: `primary`, `secondary`, `cyan`, `teal`, `purple`, `lavender`, `card-bg`, `text-muted`, `text-secondary`
- Custom CSS in globals.css: marquee keyframes, gradient mask, noise grain overlay, scrollbar styling, reduced-motion media query

### Typography

Three fonts loaded via `next/font/google` in `layout.tsx`, exposed as CSS variables:

| Variable | Font | Usage |
|----------|------|-------|
| `--font-display` | Syne | Headings (`font-display` class) |
| `--font-body` | DM Sans | Body text (default `font-sans`) |
| `--font-geist-mono` | Geist Mono | Monospace accents (`font-mono` class) |

### Components (`src/components/`)

All section components are `"use client"` and use **Framer Motion** for scroll-triggered entrance animations (`whileInView`, `viewport: { once: true }`).

- `TechStackStrip.tsx` — Infinite CSS marquee (duplicated array for seamless loop) with brand-colored icons
- `ProjectCard.tsx` — Alternating left/right layout based on index. Uses `techBrandColors` for per-tech inline-styled badges
- `ExperienceTimeline.tsx` — Vertical timeline with animated dots and staggered reveals
- `ImageCarousel.tsx` — CSS transform-based sliding carousel with glassmorphic navigation
